วิธีนำเว็บไซต์นี้ขึ้น GitHub Pages

ขั้นตอนการเปิดใช้งานเว็บไซต์ส่วนตัวแบบฟรีและแสดงผลได้ทันที

ขั้นตอนที่ 1: สร้าง Repository บน GitHub

1. ล็อกอินเข้าใช้งาน GitHub.com
2. คลิกปุ่ม New เพื่อสร้าง Repository ใหม่ ตั้งชื่อเช่น my-academic-portfolio
3. ตั้งค่าเป็น Public แล้วคลิก Create repository

ขั้นตอนที่ 2: อัปโหลดไฟล์ index.html

1. บันทึกโค้ดหน้านี้เป็นไฟล์ชื่อ index.html บนเครื่องคอมพิวเตอร์
2. บนหน้า Repository ให้เลือก uploading an existing file แล้วลากไฟล์ index.html ขึ้นไป
3. กดปุ่ม Commit changes

ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages

1. ไปที่เมนู Settings ของ Repository > เมนูด้านซ้ายเลือก Pages
2. ในส่วน Build and deployment -> Branch เลือกเป็น main (หรือ master) และเลือกโฟลเดอร์ / (root)
3. กด Save และรอ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์พร้อมใช้งานทันที!
